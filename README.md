# TaskFlow - By M.Narendra

> Your personal productivity companion

TaskFlow helps you organize tasks, track streaks, and analyze your productivity - All in a premium dark UI.

## ✨ Features
- **Smart Tasks:** Create tasks with Study, Work, Personal, Heal categories
- **Streak System:** Track your consistency daily
- **Analytics:** Completion Rate, Weekly Performance Chart
- **Achievements & Badges:** First Step, On Fire and more
- **Calendar View** & **Task Search**

### 📥 [Download APK](https://github.com/narendra-cosmic-9/TaskFlow/releases/latest)

> Direct Install: Works on Android 7.0+

## 🚀 How to Install
1. Download the APK file
2. Open File Manager -> Tap on `app-debug.apk`
3. Allow "Install from Unknown Sources" if asked
4. Tap Install -> Open TaskFlow
5. Tap + to add your first task!

## 🛠️ Built With
- Kotlin + Jetpack Compose
- Built entirely on phone using GitHub Actions
- No laptop needed!
